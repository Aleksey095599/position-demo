      Prepare the Manual Batch Request
      The browser submits one compatible Trade selection. Mixed Batching Keys are never split into independent Batches.
      data_object Зафиксировано / сохранено expand_more
      idempotencyKeyСоздаётся в браузере и передаётся в заголовке запроса.
      tradeIdsОтсортированные числовые Trade ID, передаваемые в теле запроса.
      arrow_downward
      Validate the command and resolve idempotency
      The server accepts 1 to 200 unique positive Trade IDs. A matching completed request is replayed; reuse of the same key for a different command is rejected.
      arrow_downward
      Resolve and validate source Trades
      The server loads the exact requested Trade set, sorts it by Trade ID, and validates one common Batching Key. It never plans multiple manual Batches.
      data_object Зафиксировано / сохранено expand_more
      sourceTradeIdsThe exact sorted source selection used by the domain calculation and idempotent replay.
      Batching KeyCcy Pair, Trade Date, Tenor and both Value Dates must be compatible until technical FX Swap neutralization is implemented.
      arrow_downward
      Create the Batch Aggregate
      Create the single immutable Batch aggregate under the public request idempotency key.
      database Зафиксировано / сохранено expand_more
      batch_idPrimary identifier of the single record created in batches.
      idempotency_keyНеизменяемый идентификатор запроса.
      batch_membersThe exact immutable source Trade selection used for idempotent replay.
      batch_statusTransitions atomically from BUILDING to FORMED when the aggregate is complete.
      arrow_downward
      Form the Batch
      Загрузить полностью доступные исходные сделки, проверить наличие Transfer Rate и совместимость ключевых параметров, рассчитать чистые остатки и при необходимости создать Balance Trade, Position Out и Quote Cash Out.

      Persist all results atomically
      Persist the Batch, all Trade members and technical outputs in one transaction. Any error rolls back the entire manual command.
