Trade Contract

Draft

Data supplied by originating systems when submitting concluded trades. This initial draft describes the Trade Context fields.

Trade Context

Field Description Example
Originating System ID Identifies the system in which the trade was concluded. CLICK_TRADE_EFX
Accounting System ID Identifies the accounting system where the trade is booked. AFINA
Servicing Location ID Identifies the location responsible for servicing the trade. 002
Trade Purpose ID Identifies the business purpose of the trade. CLIENT_CONVERSION
